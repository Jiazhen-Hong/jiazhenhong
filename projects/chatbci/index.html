01 / THE INTERFACE PROBLEM

A correct key
is only the
first step.

Traditional P300 spellers select one character at a time. For a complete sentence, that can mean many repeated flashes, long periods of attention, and a high cognitive burden.

ChatBCI changes the unit of communication. Language suggestions let one brain-driven selection produce a word or phrase, while the user remains in control of every choice.

CHARACTER→WORD→INTENT

02 / EVOLUTION

Two systems.
One direction.

Both systems join real-time EEG decoding with language support. ChatBCI predicts what comes next; ChatBCI-Assist moves toward local, intent-aware assistance.

LOCAL LLM

04 / CLOSED LOOP

Signal to
sentence.

Each selection stays grounded in the same real-time loop: evoke a P300 response, decode the intended key, update language context, and present the next set of options.

01

Attend

The user focuses on a desired key while rows and columns flash.

02

Detect

A P300 response identifies the row and column containing the target.

03

Decode

ChatBCI uses traditional SWLDA with eight fixed repetitions. ChatBCI-Assist uses subject-specific SWLDA with adaptive stopping.

04

Assist

Remote GPT-3.5 supplies ChatBCI suggestions; a locally deployed, ALS-adapted Llama 3.1 8B supplies ChatBCI-Assist word and phrase predictions.
