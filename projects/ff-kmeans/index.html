Use it in Python

A small API for a
geometric correction.

FFkm follows the familiar scikit-learn estimator interface. Fit, predict, and inspect the complete optimization history.

View source on GitHub ↗
quick_start.py 
from sklearn.datasets import make_blobs
from ffkm import FFKMeans

X, _ = make_blobs(
    n_samples=1000, centers=5, random_state=0
)

model = FFKMeans(
    n_clusters=5,
    ofm_method="SD",
    mfo_method="PD",
    random_state=0,
)

labels = model.fit_predict(X)
# objective after each accepted FFkm iteration
print(model.history_["inertia"])
